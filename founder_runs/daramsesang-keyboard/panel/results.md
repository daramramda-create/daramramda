## What would flip a no

- 3만원대로 세일하거나 산리오·리락쿠마 같은 캐릭터 콜라보 버전이 나오고, 자취방/기숙사 책상에 놓은 모습이랑 실제 구매자 후기를 링크 바로 연결로 볼 수 있으면 월급날(용돈날)에 살 수도 있어요.
- 제가 아는 데스크테리어 계정이나 실사용자 후기 여러 개에서 같은 키보드를 보고, 연말 세일로 3만원대까지 떨어지면 살 것 같아요.
- 산리오나 리락쿠마 같은 캐릭터 키캡이 들어가 있거나, 쿠팡 세일로 3만원 초반대까지 내려가면 위시리스트에서 꺼내서 살 수도 있어요.
- 쿠팡 리뷰에 사무실 조명 아래서 찍은 실물 사진이 여러 장 있고 영상 색이랑 똑같으면 로켓배송이라 바로 살 것 같아요.
- 같은 모델이 다른 곳보다 확실히 싸다는 가격 비교나 세일 쿠폰이 있으면 바로 살 것 같아요.
- 실제 사무실에서 녹음한 타건 소리 비교 영상으로 진짜 조용하다는 걸 보여주거나, 산리오·리락쿠마 같은 캐릭터 키캡이 같이 오면 친구랑 같이 살 수도 있음.
- 모델명이랑 자연광에서 찍은 실물 사진이나 실구매자 후기가 있고, 비교해 봤을 때 쿠팡이 제일 싸면 살 수도 있어요.
- 지금만 하는 할인이나 쿠폰으로 4만원 초반까지 내려가거나, 실물 색감이 보이는 후기 사진이 더 있으면 바로 살 것 같아요.
- 쿠팡 실구매 후기에 자연광에서 찍은 실물 사진이 많고 색이 영상이랑 똑같다는 게 확인되고, 세일로 4만원 초반까지 내려가면 그때 산다.
- 조용한 사무실에서 녹음한 실제 타건 소리랑 데시벨 비교, 그리고 보정 없는 실물 색감 사진 리뷰가 많이 달려 있으면 선물 겸 사볼 것 같아요.
- 친구 생일 선물로 같이 돈 모아서 사는 상황이거나, 3만원대로 떨어지고 실사용 리뷰가 많으면 고려함
- 쿠팡에서 3만원대로 할인하거나, 산리오·리락쿠마 같은 캐릭터 키캡이 같이 오는 버전이면 바로 살 것 같아요.
