# 근생빌라 (Low-poly Isometric Island · 9:16 릴스 · 4컷)

POV: 싸고 넓은 빌라를 구했는데 서류에 '근린생활시설'이라고 적혀 있을 때.
주제 용어: 근린생활시설 (공법 · 건축법 용도 분류)

## 브리프 요약

- 스타일: Low-poly Isometric Island (`lowpoly-island`). 정사영(orthographic) 등각 카메라, 평면 셰이딩 로우폴리, 파스텔 하늘 그라데이션.
- 주인공: 사용자가 준 다람쥐 일러스트를 로우폴리 3D로 옮긴 캐릭터. 주황 몸통(#E8A365), 짙은 주황 귀·손발·꼬리 테(#D2864B), 크림색 얼굴·배(#FBE5CB), 큰 갈색 눈과 흰 하이라이트, 분홍 볼, 빨간 동그란 입, 크게 말린 꼬리.
- 결과물: **컷별 영상 4개** (1080×1920, 24fps). 컷1 4초, 컷2 8초, 컷3 8초, 컷4 10초.
- **음성 없음**: 나레이션과 대사는 자막·말풍선으로 보여준다. 소리는 음악과 효과음만 (사용자가 나중에 녹음을 입힐 수 있게 자막 타이밍을 대본 순서대로 둔다).
- 안전지대: 릴스 UI를 피해 핵심 그림과 글자는 **좌 100px, 우 140px, 상 250px, 하 420px** 안쪽(x 100–940, y 250–1500)에만 둔다. 오른쪽 여백을 더 두는 건 좋아요·댓글 버튼 열 때문.
- 스토리보드 먼저 보여주고 승인 후 제작.

## 1. 구조 후보 세 가지

1. **방 하나가 계속 변한다 (선택)**: 같은 섬이 컷마다 새로 조립된다. 거실이 통통 튀며 세워지고(컷1), 은행 창구로 바뀌고(컷2), 서류 위로 도장이 떨어지며 빌라의 정체가 드러나고(컷3), 칠판 앞 교실로 정리된다(컷4). 이 스타일의 "짓는 것이 곧 연주" 문법이 4컷을 하나의 리듬으로 묶는다.
2. 하나의 빌라 모형을 4컷 내내 돌려 본다(턴테이블): 일관성은 좋지만 은행·칠판 장면이 억지로 붙는다.
3. 침식 구조: 완성된 꿈의 집이 컷마다 조각을 잃는다: 감정선은 강하지만 컷4 설명 장면과 맞지 않는다.

선택 이유: 4개 파일이 따로 올라가도 각각 "섬이 지어지는 순간"으로 시작해서 첫 1초 훅이 생기고, 4편을 이어 보면 같은 세계라는 게 읽힌다.

## 2. 로그라인과 흐름

싸고 넓은 집에 신난 다람쥐가 전세대출을 거절당하고, 건축물대장에서 '근린생활시설' 도장을 확인한 뒤, 계약 전에 무엇을 확인해야 하는지 알려준다.

- 설정(컷1): 거실이 통통 튀며 지어지고, 다람쥐가 두 팔을 벌린다.
- 사건(컷2): 은행 창구에서 직원이 고개를 젓고 빨간 경광등이 돈다.
- 반전(컷3): 건축물대장 위로 도장이 쾅 떨어지고, 빌라 앞면이 들리면서 아래에서 상가 간판이 솟아오른다.
- 정리(컷4): 칠판 앞에서 설명하고, 마지막 체크 표시 블록이 착지하는 클로즈업으로 끝난다.

## 3. 벤치마크

- 배울 것: 등각 디오라마 설명 영상과 퍼즐 게임 트레일러의 "조각이 착지할 때마다 음이 하나" 리듬, 넓은 여백, 파스텔 단색 면. 세로 숏폼 설명 영상의 "한 화면 한 정보" 구성.
- 가져오지 않을 것: 특정 게임의 건물, 캐릭터, UI, 글꼴, 멜로디. 실제 은행 로고나 이름 (가상의 "다람은행"만 쓴다).

## 5. 비트 시트 (초)

컷1 (4.0)
- 0.0 빈 바닥 타일 위 다람쥐가 이미 서 있다. 0.1~1.6 바닥 타일, 소파, 큰 창, 스탠드, 화분, 러그가 8분음표 간격으로 튀어나온다.
- 0.0 POV 자막 고정 (상단). 1.0 다람쥐 웅크림(예비동작) → 1.3 점프하며 두 팔 벌림 → 1.9 착지 스쿼시. 1.4~3.9 말풍선 "이 넓이에 이 가격? 완전 땡잡았다!"
- 3.5 가격표 블록이 "싸다!" 하며 튀어나온다.

컷2 (8.0)
- 0.0 은행 창구가 아래에서 솟아 착지. 0.6 다람쥐가 서류를 창구에 내민다.
- 1.0~4.6 직원 말풍선 "고객님, 이 집은 건축물대장상 주택이 아니라서요…"
- 2.6 컷 → 직원 클로즈업, 고개 좌우 2회. 3.0 경광등 켜짐(빨간 발광, 회전 빔), 자막 "🚨 전세대출 막힘" 3.0~8.0.
- 4.6 컷 → 다람쥐. 귀가 처지고 몸이 굳는다. 4.9~8.0 속마음 구름 "네? 사람 사는 집인데 집이 아니라고요?"

컷3 (8.0)
- 0.0 건축물대장(판) 위 하이앵글. 0.3~1.6 '용도' 칸으로 줌.
- 1.7 큰 도장 블록이 위에서 낙하 → 2.0 쾅 착지(스쿼시, 카메라 흔들림 1회), 빨간 인주 "제2종 근린생활시설".
- 2.6 컷 → 빌라 모형. 3.0 무음 직전 0.3초. 3.3 빌라 1층 앞면이 들리고 아래에서 상가 간판이 솟는다 (시그니처).
- 2.8~7.8 자막(나레이션) "알고 보니 원래 상가 용도로 허가받은 건물을 집처럼 꾸며놓은 '근생빌라'였던 거예요."
- 4.4~8.0 헤드라인 "집처럼 생겼지만 서류상 상가 😱"

컷4 (10.0)
- 0.0 칠판 섬이 솟는다, 다람쥐가 건축물대장을 들고 있다.
- 0.4~3.6 자막 "근린생활시설은 편의점·카페·사무실처럼 동네 생활에 필요한 시설 용도 → 주거용이 아니에요"; 칠판에 편의점·카페·사무실 아이콘 블록이 차례로 착지.
- 3.6~7.0 자막 "여기서 살면 불법 용도변경 위반건축물이 될 수 있고, 전세대출·보증보험도 막힐 수 있어요"; 칠판에 "≠ 주택" 집 아이콘에 X.
- 7.0~10.0 자막 "계약 전 건축물대장 '용도' 칸 꼭 확인!"; 칠판 요약 "근린생활시설 = 상가 용도 ≠ 주택 → 건축물대장 용도 체크 ✅", 마지막 체크 블록 착지 클로즈업.
- 컷4 나레이션은 원문(약 110자)이 10초 안에 다 읽히지 않아 의미를 살려 3줄로 나눴다.

## 8. 자막·타이틀 디자인

- 글꼴: 자막과 말풍선은 둥근 한글 글꼴 **Jua**(OFL), 헤드라인과 도장은 **Black Han Sans**(OFL), 칠판 글씨는 손글씨 **Gaegu**(OFL). 이모지는 Noto Color Emoji.
- 자막: 박스 없이 따뜻한 흰색 + 부드러운 남색 그림자, 하단 안전선(y 1500) 위에 중앙 정렬, 옆에 시간대 색을 따르는 작은 육각 타일 아이콘.
- 말풍선은 3D 공간의 인물을 따라가는 흰 둥근 판 (말풍선 꼬리는 인물 머리 화면 좌표에서 계산).
- 헤드라인(🚨 전세대출 막힘, 집처럼 생겼지만 서류상 상가 😱)은 글자가 하나씩 아래에서 솟아 튀어오르며 자리잡는다.
- 모든 글자는 안전지대 안쪽.
