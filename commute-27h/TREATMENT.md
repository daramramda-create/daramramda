# 출퇴근 한 달 27시간 / 직주근접 (Tilt-Shift Miniature · 9:16 릴스 · 4컷)

[2030부동산 숏츠]. 주인공: 지난 영상과 같은 다람쥐 (사용자 일러스트), 이번엔 틸트시프트 세계에 맞게 매끈한 몸(부드러운 광택 재질, 실제보다 20~30% 크게)으로.

## 브리프 요약

- 스타일: Tilt-Shift Miniature (`tilt-shift`). 높은 곳에서 내려다본 실사 같은 도시, 가운데 가로 띠만 선명하고 위아래는 흐림, 진한 채도, 타임랩스 끊김(8Hz).
- 결과물: **컷별 영상 4개**, 1080×1920, 24fps. 컷1 6초, 컷2 7초, 컷3 9초, 컷4 8초 (합 30초).
- **음성 없음** (이 환경에서 한국어 TTS 서버가 막혀 있음): 나레이션은 자막으로. 대본의 [강조] 단어는 강조색.
- 안전지대: 핵심 그림과 글자는 x 100–940, y 250–1500 안쪽.
- 숫자는 사용자 대본 그대로 (36.5분 + 37.4분 = 74분, ×22일 = 27시간, 출퇴근 단축 40.2%, 주거비 절약 17.8%). 출처는 사용자가 준 대본.

## 1. 구조 후보

1. **시간이 주인공 (선택)**: 컷1 지하철(타임랩스로 흘러가는 바깥 도시), 컷2 계산(실시간, 숫자 하나하나), 컷3 이사(×40 타임랩스로 이동 → 상자 내려놓는 순간 ×1 실시간으로 뚝 떨어짐: 이 스타일의 "속도 낙하"를 시그니처로), 컷4 지도(위에서 내려다본 동네, 한 걸음 거리; 마지막에 다시 ×40으로 빨라지며 지하철 문 소리 → 컷1로 루프).
2. 한 사람의 하루 동틀녘→밤 고정 시점: 시간 감각은 좋지만 계산·그래프 정보가 들어갈 자리가 없다.
3. 릴레이 구조(띠가 출근자들을 차례로 넘겨받음): 다람쥐 한 명의 이야기가 약해진다.

선택 이유: 주제가 "시간"이고, 틸트시프트의 본질도 "시간 조작"이라 대본과 매체가 같은 말을 한다. 화면 오른쪽 위 작은 **타임랩스 속도계**(`×40 TIME-LAPSE` / `×1 REAL TIME`)가 그 장치를 관객에게 보여준다.

## 2. 로그라인

출퇴근 시간을 처음 계산해 본 다람쥐가 한 달 27시간에 충격받고, 회사 옆으로 이사해 '직주근접'의 여유를 얻는다. 마지막 말 "안 그러면 너도 한 달에…" 끝에 지하철 문이 닫히며 처음으로 돌아간다.

## 3. 벤치마크

- 배울 것: 틸트시프트 타임랩스 사진·영상의 높은 시점, 얇은 초점 띠, 장난감처럼 끊기는 차량, 구름 그림자. 미니멀리즘 마림바 펄스.
- 가져오지 않을 것: 특정 도시·랜드마크·지하철 노선 색과 로고, 기존 곡.

## 5. 비트 시트

- 컷1: 0.0 문 닫히는 소리(쉬익-탁), 0.3 자막 "POV: 출퇴근 시간 처음 계산해 본 직장인", 3.5 자막 "한 달에… [27시간]?", 4.0 "띠용" + 다람쥐 눈 커지고 손잡이에서 미끄러질 뻔. 타이틀 "출퇴근만 한 달 27시간?!" 0–6 상단.
- 컷2: 0.5 / 1.25 / 2.0 / 2.75 / 3.5 계산기 키 누름 → 패널 36.5분, +37.4분, =74분, ×22일 (각 팝). 4.5 "딩" =27시간 큰 패널, 다람쥐 뒤로 넘어질 듯 놀람. 자막 3줄 순서대로, 핵심 자막 "하루 평균 [74분] → 한 달 [27시간]".
- 컷3: 0–4.0 ×40 이동(끊김), 4.0 상자 내려놓기 "툭" → ×1, 4.5 / 5.0 막대 "슈욱" 상승 (40.2%, 17.8%), 핵심 자막 "이사 이유 1위 = [출퇴근 단축]" 4.5부터.
- 컷4: 0.2 용어 카드 "직주근접 = 직장 + 주거 가까움" 팝 + "띵", 커피 홀짝. 6.0 ×1 → ×40 가속, 7.6 지하철 문 닫힘(루프).

## 6. 큐 맵 / 사운드

- 112 BPM 마림바·글로켄슈필·우드블록 펄스 (라이히식 반복). 컷2는 계산기 버튼음이 리듬, 컷3은 ×1 순간 음악 디지털 무음 + 실제 소리(새, 먼 차 소리), 그래프 상승 때 다시 시작.
- 타임랩스 구간: 음악 + 희미한 "빨리 감기" 히스, 딸깍 소리. 실시간: 엔진 공회전, 새, 발소리.

## 7. 자막·타이틀

- 자막은 이 세계의 표지판: 도로 표지판 같은 파란 판 + 흰 고딕(Noto Sans KR 굵게), 강조어는 노란색. 하단 안전선 위.
- 타이틀(컷1)·핵심 자막·용어 카드: 지하철 안내판/역명판 디자인(남색 판, 흰 글씨, 강조 노랑).
- 속도계: 오른쪽 위 작은 고정폭 글꼴(Overpass Mono) `×40 TIME-LAPSE` / `×1 REAL TIME`.
